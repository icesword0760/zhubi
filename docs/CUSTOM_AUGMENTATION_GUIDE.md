# 细粒度数据增强自定义配置指南

## 📋 功能概述

现在支持对数据增强进行**细粒度控制**，可以精确到每个具体的增强方法，而不仅仅是类别级别的开关。

---

## 💡 使用技巧

### 1. 类别复选框的作用

点击类别名称旁的复选框（如"💡 亮度调整"），可以一键全选/取消该类别下的所有方法。

### 2. 展开/折叠类别

点击类别名称或左侧的箭头（▶/▼），可以展开或折叠该类别，方便管理。

### 3. 实时预览样本数

每次勾选或取消方法时，界面会自动计算并显示增强后的样本数量。

**计算公式**：
```
总样本数 = 原始样本数 × (1 + 勾选的方法数)
```

**示例**：
- 原始样本：100个标注框
- 勾选方法：5个
- 增强后样本：100 × (1 + 5) = 600个样本

## 🔧 技术细节

### 前端实现

**HTML结构**：
```html
<div class="aug-category">
    <input type="checkbox" data-aug-category="brightness">
    <span>💡 亮度调整 (5种)</span>
    
    <div id="brightness-methods">
        <input type="checkbox" data-aug="brightness" data-method="bright_1_2">
        <span>亮度+20%</span>
        ...
    </div>
</div>
```

**JavaScript收集方法**：
```javascript
function getCustomAugmentationCategories() {
    const methods = [];
    const checkboxes = document.querySelectorAll(
        '#customAugmentation input[data-method]'
    );
    checkboxes.forEach(checkbox => {
        if (checkbox.checked) {
            methods.push(checkbox.getAttribute('data-method'));
        }
    });
    return methods;
}
```

### 后端实现

**接收配置**：
```python
# train_manager.py
custom_methods = augmentation_config.get('categories', None)
# 'categories' 现在包含方法列表，如：
# ['bright_1_2', 'contrast_high', 'dpi_2x', ...]
```

**应用增强**：
```python
# data_augmentor.py
def _get_augmentation_methods(self, strategy, custom_methods):
    if strategy == 'custom' and custom_methods:
        # 根据方法名筛选增强函数
        all_methods_dict = {...}  # 所有方法的字典
        selected = []
        for method_name in custom_methods:
            if method_name in all_methods_dict:
                selected.append((method_name, all_methods_dict[method_name]))
        return selected
```

## 📊 最佳实践

### 1. 从少到多

**推荐流程**：
1. 第一轮：勾选5-8个核心方法（亮度、对比度、DPI各2-3个）
2. 训练并评估效果
3. 根据效果调整：
   - 如果泛化性不足，增加更多方法
   - 如果过拟合，减少方法数量

### 2. 关注目标场景

**移动端**：重点选择DPI和亮度相关方法  
**Web端**：重点选择压缩和缩放相关方法  
**桌面端**：重点选择锐化和高分辨率相关方法  
**图标识别**：重点选择边缘和亮度相关方法

### 3. 边缘检测慎用

边缘检测方法会显著改变图像视觉风格，只在以下情况使用：
- ✅ 形状/轮廓识别任务
- ✅ 线框图/示意图识别
- ❌ 真实UI元素识别（不推荐）
- ❌ 图标识别（谨慎使用）

### 4. 噪声和压缩

噪声和压缩方法适用于：
- ✅ 低质量图像识别
- ✅ 网络传输后的图像
- ✅ 截图识别
- ❌ 高清图标识别（不需要）

## ❓ 常见问题

### Q1: 勾选太多方法会有什么影响？

**A**: 样本数量大幅增加，训练时间也会相应延长。但更重要的是：
- ✅ 好处：模型泛化能力更强
- ⚠️ 风险：如果方法选择不当，可能导致过度增强

**建议**：第一次使用10-15个方法，观察效果后再调整。

### Q2: 如何知道应该勾选哪些方法？

**A**: 根据目标应用场景：
1. 分析实际使用环境（移动端/Web/桌面）
2. 思考可能遇到的变化（亮度、分辨率、清晰度等）
3. 勾选对应的增强方法
4. 参考本文档的"应用场景"部分

### Q3: 细粒度配置和预设策略可以混用吗？

**A**: 不可以。选择"自定义"后，预设策略会被忽略，完全由你的勾选决定。

### Q4: 如何快速恢复到某个预设策略？

**A**: 
1. 将"增强策略"切换回预设选项（如"中等"）
2. 或者手动勾选对应数量的方法：
   - 轻量级 ≈ 3个方法
   - 中等 ≈ 6个方法
   - 激进 ≈ 10个方法

### Q5: 类别复选框和具体方法复选框的关系？

**A**: 
- 类别复选框：控制该类别下所有方法的勾选状态
- 方法复选框：独立控制每个具体方法
- 它们是"全选/取消全选"的关系，不是"启用/禁用"的关系
