# 🚀 快速开始指南

## 一、安装和启动

### 1. 安装依赖

```bash
cd zhubi
pip install -r requirements.txt
```

### 2. 启动服务

**方式一：使用启动脚本**
```bash
chmod +x start.sh
./start.sh
```

**方式二：直接运行**
```bash
python app.py
```

### 3. 打开浏览器

访问 http://localhost:8000

## 二、完整工作流程

### 步骤 1: 创建项目

1. 点击「创建第一个项目」或「新建项目」
2. 填写项目信息：
   - **项目名称**: 例如 "垂直应用图标识别"
   - **项目描述**: 简要说明项目目的
   - **标注类别**: 每行一个类别名称
     ```
     button
     icon
     text_box
     input_field
     checkbox
     ```
3. 点击「创建项目」

### 步骤 2: 上传图片

1. 进入项目，点击「标注」
2. 点击「⬆️ 上传图片」
3. 选择要标注的图片（支持批量上传）
4. 等待上传完成

### 步骤 3: 标注数据

#### 标注操作
- **绘制标注框**: 鼠标拖拽绘制矩形框
- **选择类别**: 点击右侧类别按钮
- **删除标注框**: 选中后点击「删除」或按 `D` 键
- **保存标注**: 点击「💾 保存」或按 `S` 键

#### 快捷键
| 快捷键 | 功能 |
|--------|------|
| `N` | 下一张图片 |
| `P` | 上一张图片 |
| `S` | 保存当前标注 |
| `D` | 删除选中的框 |
| `ESC` | 取消当前绘制 |

#### 标注技巧
- 尽量精确框选目标
- 避免框选重叠区域
- 确保每个对象都有正确的类别
- 定期保存避免丢失

### 步骤 4: 导出数据

1. 进入「数据导出」页面
2. 选择项目
3. **选择导出格式**:
   - **Florence-2** ⭐ (推荐，用于本项目训练)
   - COCO (通用格式)
   - YOLO (YOLOv8训练)
   - Pascal VOC (传统格式)
   - CSV (数据分析)

4. **配置数据集划分**:
   ```
   训练集: 70%
   验证集: 20%
   测试集: 10%
   ```

5. 可选择启用数据增强
6. 点击「📦 导出数据集」
7. 下载ZIP压缩包

### 步骤 5: 准备训练数据

1. 解压导出的ZIP文件
2. 将内容复制到训练数据目录:
   ```bash
   mkdir -p data/models/your_project_id/florence2_data
   cp -r exported_data/* data/models/your_project_id/florence2_data/
   ```

### 步骤 6: 训练模型

1. 进入「模型训练」页面
2. 选择项目
3. **配置训练参数**:
   - **Epochs**: 10-20 (推荐从10开始)
   - **Learning Rate**: 1e-6 (默认)
   - **Batch Size**: 4 (根据显存调整)
   - **训练设备**: 自动选择 (优先GPU)

4. **LoRA配置** (推荐开启):
   - ✅ 使用LoRA低秩适配
   - Rank (r): 8
   - Alpha: 8

5. 点击「🚀 开始训练」
6. 实时查看训练日志
7. 等待训练完成

### 步骤 7: 部署模型

训练完成后：

```bash
# 复制模型到OmniParser
cp -r data/models/your_project_id/final_model ../weights/icon_caption_florence_custom

# 修改OmniParser配置使用新模型
# 在omni.py或gradio_demo.py中修改模型路径
```

## 三、常见问题

### Q1: 训练时显存不足怎么办？

**解决方案**:
1. 减小 Batch Size (4→2→1)
2. 确保启用 LoRA
3. 降低图片分辨率
4. 使用 CPU 训练（会很慢）

### Q2: 标注框保存失败？

**检查**:
1. 是否选择了类别
2. 框的尺寸是否太小（<10px）
3. 检查浏览器控制台错误
4. 刷新页面重试

### Q3: 导出的数据格式不对？

**确认**:
1. 是否完成标注
2. 选择正确的导出格式
3. 数据集划分比例之和=100%
4. 查看导出的ZIP文件内容

### Q4: 训练loss不下降？

**可能原因**:
1. 学习率太大或太小
2. 训练数据太少（<50张）
3. 标注质量问题
4. 类别分布不均衡

**建议**:
- 增加训练数据
- 调整学习率（1e-7 ~ 1e-5）
- 检查标注质量
- 增加训练轮数

### Q5: 如何提高识别准确率？

**方法**:
1. **增加数据量**: 每类至少50-100张
2. **数据多样性**: 不同背景、光照、角度
3. **标注质量**: 精确框选，避免遗漏
4. **数据增强**: 导出时启用
5. **增量训练**: 混合新旧数据
6. **调整参数**: 尝试不同的学习率和epochs

## 四、高级技巧

### 数据增强策略

导出时启用数据增强，包括：
- 随机旋转 (-15° ~ 15°)
- 随机缩放 (0.8 ~ 1.2)
- 亮度调整
- 对比度调整
- 水平翻转

### LoRA 参数调优

```python
# 减少训练参数
lora_r = 4  # 更小的rank

# 增加训练能力  
lora_r = 16
lora_alpha = 32
```

### 混合训练

防止灾难性遗忘：
1. 保留一部分原训练集样本
2. 与新数据混合训练
3. 监控旧类性能

## 六、性能优化

### 标注效率
- 使用快捷键
- 批量上传图片
- 设置合理的类别顺序

### 训练速度
- 使用GPU (CUDA/MPS)
- 启用LoRA
- 适当的batch size
- 使用fp16混合精度

### 存储空间
- 定期清理导出文件
- 删除不需要的训练检查点
- 压缩原始图片

